# 🚀 한국투자 Open API 기반 미국주식 초단타 스캘핑 자동매매 시스템

## 📋 시스템 개요

GPT 분석과 한국투자 Open API를 활용한 **완전 자동화된 미국 주식 초단타 스캘핑 시스템**입니다.

### 🎯 핵심 특징

- **🏛️ 한국투자 Open API**: 공식 API를 통한 안정적인 미국 주식 거래
- **🤖 GPT 분석**: OpenAI GPT를 활용한 실시간 시장 분석
- **⚡ 초단타 스캘핑**: 평균 보유시간 5분 이하의 고빈도 거래
- **🌐 24시간 거래**: 프리마켓 + 정규장 + 애프터마켓 전체 시간 지원
- **📱 텔레그램 알림**: 실시간 거래 알림 및 일일 리포트
- **🛡️ 리스크 관리**: 자동 손절/익절, 일일 손실 한도, 서킷 브레이커
- **� 성과 분석**: 실시간 성과 추적 및 백테스트

## 🌍 전체 거래 시간 지원 (한국 시간 기준)

### 📅 썸머타임 자동 적용
- **썸머타임 (3월~11월)**: 미국 동부 시간 UTC-4
- **표준시 (11월~3월)**: 미국 동부 시간 UTC-5

### ⏰ 거래 세션 (한국 시간)

| 세션 | 썸머타임 | 표준시 | 설명 |
|------|----------|---------|------|
| 🌅 프리마켓 | 17:00 - 22:30 | 18:00 - 23:30 | 높은 변동성, 뉴스 반응 |
| 🏛️ 정규장 | 22:30 - 05:00 | 23:30 - 06:00 | 메인 거래 시간 |
| 🌆 애프터마켓 | 05:00 - 09:00 | 06:00 - 10:00 | 실적 발표 후 거래 |

### 🎯 스캘핑 활성 시간
- **프리마켓 전체**: 높은 변동성 활용
- **정규장 오픈 1시간**: 장 시작 momentum
- **정규장 마감 2시간**: 마감 전 활발한 거래
- **애프터마켓 첫 1시간**: 실적 발표 반응

## 🚀 시작하기

### 1. 환경 설정

```bash
# 1. 저장소 클론
git clone <repository_url>
cd scalping_system

# 2. 가상환경 생성
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 의존성 설치
pip install -r requirements.txt

# 4. 환경 변수 설정
cp .env.example .env
```

### 2. 한국투자 Open API 설정

#### 📝 API 키 발급
1. [한국투자증권 홈페이지](https://securities.koreainvestment.com) 접속
2. KIS Developers > Open API 신청
3. 실전투자용 / 모의투자용 앱키 발급
4. 해외주식 거래 권한 확인

#### 🔑 환경 변수 설정 (.env 파일)
```bash
# 한국투자 Open API 설정
KIS_APP_KEY=your_production_app_key_here
KIS_APP_SECRET=your_production_app_secret_here
KIS_PAPER_APP_KEY=your_paper_app_key_here
KIS_PAPER_APP_SECRET=your_paper_app_secret_here
KIS_ACCOUNT_NO=your_account_number_8_digits
KIS_PRODUCT_CODE=01

# OpenAI API 설정
OPENAI_API_KEY=your_openai_api_key_here

# 텔레그램 알림 설정
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
TELEGRAM_CHAT_ID=your_telegram_chat_id_here
TELEGRAM_ENABLED=true
```

### 3. 텔레그램 알림 설정

#### 📱 텔레그램 봇 생성
1. **BotFather와 채팅**
   - 텔레그램에서 `@BotFather` 검색
   - `/newbot` 명령 입력
   - 봇 이름 설정 (예: "ScalpingBot")
   - 봇 토큰 복사 → `TELEGRAM_BOT_TOKEN`에 입력

2. **채팅 ID 확인**
   - 생성된 봇과 채팅 시작
   - 아무 메시지 전송
   - 브라우저에서 `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates` 접속
   - `chat.id` 값 복사 → `TELEGRAM_CHAT_ID`에 입력

#### 📳 알림 종류
- **거래 알림**: 매수/매도 시 실시간 알림
- **포지션 현황**: 30분마다 보유 종목 상태
- **시장 상태**: 세션 변경 시 알림
- **일일 리포트**: 장 마감 후 종합 리포트
- **시스템 알림**: 오류, 서킷 브레이커 등

## 🔧 고급 설정

### 📊 스크리닝 조건 커스터마이징
`config/config.py`에서 다음 설정을 조정할 수 있습니다:

```python
SCREENING_CONFIG = {
    "min_volume": 1000000,       # 최소 거래량
    "min_price": 5.0,            # 최소 주가
    "max_price": 500.0,          # 최대 주가
    "gap_threshold": 0.03,       # 갭 상승 임계값 (3%)
    "volume_spike": 2.0,         # 거래량 급증 배수
}
```

### 🎯 스캘핑 전략 조정
```python
SCALPING_CONFIG = {
    "max_position_size": 10000,  # 최대 포지션 크기
    "max_positions": 5,          # 최대 동시 포지션 수
    "profit_target": 0.005,      # 익절 목표 (0.5%)
    "stop_loss": 0.003,          # 손절 기준 (0.3%)
    "holding_time_limit": 300,   # 최대 보유 시간 (초)
}
```

### 🛡️ 리스크 관리 설정
```python
RISK_MANAGEMENT = {
    "max_daily_loss": 1000,      # 일일 최대 손실
    "max_drawdown": 0.05,        # 최대 낙폭 (5%)
    "circuit_breaker": True,     # 서킷 브레이커 활성화
    "position_sizing": "fixed",  # 포지션 사이징 방식
}
```
